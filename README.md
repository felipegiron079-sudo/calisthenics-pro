# CALISTHENICS PRO — starter Expo

Prototipo multiplataforma para Android e iOS, con interfaz oscura y contenido inicial en español.

## Incluye
- Navegación: Inicio, Trucos, Entrenar, Progreso y Perfil.
- Biblioteca inicial de 30 habilidades estáticas y dinámicas.
- Búsqueda y filtros por tipo y dificultad.
- Fichas con descripción y progresiones.
- Rutina base de ejemplo.
- Seguimiento de progresiones durante la sesión.

## Requisitos
- Node.js LTS
- Expo Go en el teléfono (para probar)
- Xcode en macOS para compilación local de iOS; Android Studio para emulador Android.

## Ejecutar
```bash
npm install
npx expo start
```
Escanea el QR con Expo Go. Para compilar binarios de distribución, configura EAS Build y los identificadores de paquete definitivos.

## Antes de publicar
Este es un starter funcional, no una app de producción ni una copia de Calisteniapp. El progreso todavía es temporal (estado en memoria). Faltan persistencia local/nube, cuentas, vídeos originales, animaciones, notificaciones, pruebas en dispositivos, accesibilidad, políticas de privacidad, revisión de seguridad y publicación en App Store / Google Play.

Los movimientos acrobáticos y de fuerza avanzada deben incluir instrucciones de seguridad y progresiones supervisadas. El catálogo es una base inicial, no una lista exhaustiva de todos los trucos existentes.
